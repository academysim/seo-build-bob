## Project description

Academy Sim Racing runs five live websites that I built five years ago with no coding background, from copy-pasted Python scripts. Every fix had to be made five times, and there was no test suite to catch mistakes. With IBM Bob, we modernized the code without changing what visitors see: one shared audit engine instead of five copies, shared constants for business details, a dry-run mode for the build, and 202 automated tests where there were 13 hand-written checks. All 263 fingerprinted files (136 deployed, 127 source) are still byte-identical to the pre-Bob version, and GitHub checks every push.

## Tech stack

- IBM Bob (bob CLI): planning, refactoring, test writing, CI setup, documentation
- Python 3, standard library only (unittest, hashlib, ast, pathlib, re, json, subprocess)
- Static HTML, CSS and JSON-LD generated by Python
- SHA-256 fingerprints of every shipped file (`BASELINE-site-hashes.txt`, `BASELINE-upload-hashes.txt`)
- GitHub Actions (`.github/workflows/gates.yml`)
- Netlify (hosting for the five live sites and the demo page)
- Google Analytics 4 (tag presence checked by the audits)
- Claude Code: reviewed Bob's commits and numbers, fixed one CI step, and helped prepare the video and submission materials. The modernization itself was done by Bob.
