    - TestZeroStagedGuard: verifies the 'staged nothing' failure guard exists in source
      (cannot run the full script because it resolves ROOT from __file__, not cwd)

    the main loop never runs. This is the correct approach: the constants are what

    - TestMissingPath: path in inventory absent from upload/ → verify() fails

    - TestEmptyStagingDir: upload/ exists but empty → verify() fails
    - TestGoldenPath: upload/ matches inventory exactly → verify() passes
    - TestRecord: record() creates correct inventory; refuses to record empty upload/
